# Sample data for testing

All names, numbers, GSTINs and references here are made up for testing. They do not belong to any real company.

| File | Use it to test |
|---|---|
| `sample-bank-statement.csv` | Bank & Cash employee: bank reconciliation (BRS) |
| `sample-bank-ledger.csv` | The books side of the same bank account |
| `sample-vendor-bills.csv` | Accounts Payable employee: bill checks and payment proposal |

The expected results are in [TESTING.md](../TESTING.md). They are kept out of this folder on purpose, so that an AI employee working on these files cannot read the answers.
